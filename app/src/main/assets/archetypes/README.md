# Katalog Arketipe Kamera (`assets/archetypes/`)

Folder ini disiapkan untuk menampung sekitar **15 arketipe** kamera dan sensor sebagai fondasi pengelompokan katalog sebelum perluasan resep kamera di M6.

Setiap entri kamera di `assets/cameras/` merujuk ke salah satu `archetype` di folder ini serta mencantumkan `confidence`, `sources`, dan `calibrationStatus`.

**Catatan penting:** Seluruh parameter numerik pada tahap awal berstatus `draft` (perkiraan awal) dan bukan klaim akurasi absolut sebelum melalui kalibrasi dengan foto referensi.
